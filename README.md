# Provisión de la Sabana: Carnes y Abarrotes 🥩🛒

Bienvenido al repositorio oficial de **Provisión de la Sabana**, una plataforma web diseñada para ofrecer presencia digital a una empresa local líder en la comercialización de productos cárnicos y abarrotes de alta calidad[cite: 1, 2].

Puedes acceder a la versión en vivo del proyecto aquí:

## 📋 Descripción del Proyecto
Este sitio web es el resultado del **Taller Práctico de GitHub**, enfocado en el desarrollo frontend y la implementación de flujos de trabajo profesionales[cite: 1]. El proyecto incluye:
*   **Catálogo de productos**: Visualización organizada de carnes y abarrotes[cite: 1, 2].
*   **Galería Corporativa**: Espacio visual que resalta la frescura y calidad de la marca[cite: 1].
*   **Contacto**: Información directa para atención al cliente y ubicación[cite: 1, 2].

## 🛠️ Tecnologías y Herramientas
*   **Frontend**: HTML5 semántico y CSS3 para un diseño responsivo y profesional[cite: 1, 2].
*   **Control de Versiones**: Git para la gestión local de cambios[cite: 1].
*   **Colaboración**: GitHub para el alojamiento del código y manejo de ramas/pull requests[cite: 1, 2].
*   **Despliegue**: GitHub Pages para el hosting gratuito[cite: 1].

---

## 🚀 Proceso de Despliegue en GitHub Pages
Para publicar este sitio web, se siguió el flujo de despliegue continuo integrado en GitHub[cite: 1, 2]:

1.  **Preparación del Repositorio**: Se aseguró que el archivo principal de entrada fuera nombrado `index.html` y se encontrara en la raíz del proyecto[cite: 1].
2.  **Configuración de Rama**: Se realizaron todos los *merges* necesarios de las ramas de características (`feature/`) hacia la rama principal `main`[cite: 1, 2].
3.  **Activación del Servicio**: 
    *   Navegué a la pestaña **Settings** del repositorio en GitHub[cite: 1, 2].
    *   Seleccioné la sección **Pages** en el menú lateral[cite: 1].
    *   Configuré el **Source** como "Deploy from a branch", seleccionando la rama `main` y la carpeta `/root`[cite: 1, 2].
4.  **Verificación**: GitHub Actions procesó los archivos y generó la URL pública en menos de un minuto[cite: 1].

## 💻 Flujo de Trabajo (Git Workflow)
Durante el desarrollo se aplicaron los siguientes comandos fundamentales[cite: 1]:
*   `git clone`: Para obtener la base del proyecto[cite: 1].
*   `git checkout -b feature/seccion`: Para trabajar de forma aislada en cada módulo (Catálogo, Contacto, Galería)[cite: 1, 2].
*   `git commit -m`: Para registrar de forma descriptiva cada avance técnico[cite: 1].
*   `git push origin`: Para subir los cambios y permitir la revisión por pares mediante Pull Requests[cite: 1, 2].
